# Place Cell Variance Analysis
## Table of contents

This project is a new statistical test to estimate the contribution of individual stimulus variables to the firing rates of purported place cell neurons.

You can check out the notebooks to see some examples of the method in action. The "dusz" dataset is a collection of head direction cells from [Peyrache et al. 2015](https://www.nature.com/articles/nn.3968) and can be downloaded from [CRCNS](https://crcns.org/data-sets/thalamus/th-1/about-th-1). The "pfeiffer" dataset is a collection of place cell recordings from [Pfeiffer and Foster 2013](https://www.nature.com/articles/nature12112).

This is a work in progress as the main method is still being worked on, please forgive the dust.
