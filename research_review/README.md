# Research review

Planning and review material written in September and October 2026. None of it is part of the analysis pipeline. Read it for context on where the project could go next.

- [RESEARCH_REVIEW.md](RESEARCH_REVIEW.md): a review of the manuscript's claims against the literature and the code, with suggested experiments.
- [WEI_RESEARCH_PROGRAM.md](WEI_RESEARCH_PROGRAM.md) and [TRANSFORMER_MECHANISMS_DIRECTION.md](TRANSFORMER_MECHANISMS_DIRECTION.md): possible follow-up directions.
- [hypothesis_plans/](hypothesis_plans/README.md): three possible follow-up papers, each written as a tree of claims. `PROJECT_HANDOFF.md` lists which existing assets can be reused.
- `source_notes/`: the literature notes and code audit the reviews draw on.
- `method_diagnostics.py`: a standalone check of the estimator. Its saved output is in `source_notes/method_diagnostics.json`.

Some of these documents were first written against an anonymized partial copy of this repository, so they sometimes say files are missing that are actually in the repo. They also refer to absolute paths on the machine they were written on (`/Users/moo/...`). Read those as paths relative to the repository root.
